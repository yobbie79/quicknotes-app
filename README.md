# QuickNotes App

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It allows users to create, organise, search, and delete notes, with notes saved in the browser using localStorage.

## Features

- Create notes under Personal, Work, and Study categories.
- Validate note input with a 200-character limit.
- Search notes without case sensitivity.
- Delete individual notes.
- Save notes automatically using localStorage.
- Responsive design for desktop and mobile screens.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser or use the Live Server extension.
4. Start creating and managing your notes.
